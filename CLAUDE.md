# dracula-rdm

Dracula terminal color scheme for Devolutions Remote Desktop Manager (RDM).

- `Dracula.txt` is RDM's native terminal color export. Keep it byte-for-byte as RDM produces it; do not reformat.
- No build or tests. Check by importing the file in RDM (File > Settings > Terminal > Types) and running a color-swatch loop in an SSH session.
- Submission: repo is created from dracula/template; submit by opening an issue at https://github.com/dracula/dracula-theme/issues/new with the repo link. Dracula then moves the repo into their org.
- Format docs with `npx prettier . --write` before submitting.
